## What this site is

haruhime.moe is the home page for haruhime's osu! tools: it describes them, links to them, lists the libraries they're built from and shows their README files. It also runs the haruhime account, the osu! sign-in packs, pools, bb, harumin and tourney share. Your account is yours to delete on [your account page](/account). Using the site means you accept these terms.

## The libraries

The @haruhimemoe packages shown on [Libraries](/libraries) are released under the MIT license. Each package's license file governs its use; the docs pages here are a rendering of each repo's README and may lag the repo.
