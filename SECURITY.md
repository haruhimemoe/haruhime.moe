# Security

Please report vulnerabilities privately instead of opening an issue:

1. **GitHub:** [report a vulnerability](https://github.com/haruhimemoe/haruhime.moe/security/advisories/new) (private vulnerability reporting).
2. **Email:** contact@haruhime.moe, if you can't use GitHub.

Include steps to reproduce and the impact you expect. You'll get a reply within 7 days.

In scope: this repository and the live site at https://www.haruhime.moe. Only the current `main` branch and the live site are supported.

packs, pools and the `@haruhimemoe` packages have their own repositories and SECURITY.md files; report problems with them there. Report problems in third-party services (osu!, the beatmap mirror) to those services.
