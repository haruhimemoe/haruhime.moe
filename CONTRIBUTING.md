# Contributing

Read [AGENTS.md](./AGENTS.md) first; it has the conventions.

## Run it locally

Requires Bun 1.4+ and Node 24+.

```bash
bun install && bun dev
```

Then open http://localhost:3000. No environment variables are needed.

## Checks

Run these before opening a PR. All four must pass:

```bash
bun run check && bun run typecheck && bun run test && bun run build
```

| Script | What it does |
| --- | --- |
| `bun run check` / `check:fix` | Biome lint + format + import order |
| `bun run typecheck` | Route type generation + `tsc` |
| `bun run test` | Vitest (unit and components projects) |
| `bun run test:coverage` | Tests with v8 coverage |
| `bun run build` | Production build; every route must show as static (○) |

`bun install` sets up a lefthook pre-commit hook that runs Biome on staged files.

## Brand files

The logos, favicon, Apple icon and link preview are generated by [@haruhimemoe/brand](https://github.com/haruhimemoe/brand) and committed. Don't edit them by hand.

`@haruhimemoe/brand` is a dev dependency, so `bun install` fetches it. To regenerate the files, run this from the repo root:

```bash
bunx haruhime-brand haruhime
node --input-type=module -e '
import { writeFileSync } from "node:fs";
import { iconSvg, PRODUCTS } from "@haruhimemoe/brand";
for (const key of ["packs", "pools", "sheets"]) {
  writeFileSync(`public/brand/${key}-icon.svg`, iconSvg(PRODUCTS[key]));
}'
```

The first command writes `public/brand/haruhime-*` and `src/app/icon.svg`, `apple-icon.png`, `opengraph-image.png` and its alt text. The second writes the tool icons the homepage and `/brand` use. Run `bun run test` afterwards: it checks the palette still matches `src/app/globals.css`. Commit the changes.
